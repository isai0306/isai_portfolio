

# Isai Kumar — Portfolio Website

## Overview
A dark-themed, highly interactive personal portfolio for a Full Stack Developer, featuring 3D elements, smooth animations, and a premium aesthetic.

## Design System
- **Theme**: Dark background (#0a0a0f) with accent gradients (blue-purple: #6366f1 → #8b5cf6)
- **Glassmorphism**: Frosted glass cards with backdrop-blur
- **Typography**: Bold modern headings, clean body text
- **Custom cursor**: Glowing dot that expands on hover over interactive elements

## Sections

### 1. Hero Section
- Large animated heading "Hi, I'm Isai Kumar" with typing effect
- Subtitle and description with staggered fade-in animations
- Particle background using Three.js (floating geometric shapes)
- Two CTA buttons: "View Projects" and "Contact Me"
- Scroll-down indicator

### 2. About Me
- Professional summary with scroll-triggered reveal animation
- Clean layout with decorative accent elements

### 3. Skills Section
- Two categories: Technical and Interpersonal
- Interactive skill cards with hover animations and progress bars
- 3D rotating skill icons using Three.js
- Skills: Java, React.js, JavaScript, HTML, CSS, MySQL, Node.js, Firebase, Git, GitHub, Postman, Apache Tomcat, n8n + soft skills

### 4. Projects Section
- Four project cards with glassmorphism styling and hover lift effects
- Each card: title, description, tech stack badges, "View Project" and "GitHub" buttons
- Projects: Online Exam System, Student Result Management, Student & Mentor Dashboard, Automotive Platform
- Staggered scroll-triggered animations

### 5. Contact Section
- Animated contact form (Name, Email, Message) with floating labels
- Social links: LinkedIn, GitHub, LeetCode
- Form validation with visual feedback

## Technical Features
- Framer Motion for scroll animations, page transitions, micro-interactions
- Three.js (@react-three/fiber) for 3D floating objects in hero
- Custom animated cursor component
- Smooth scrolling between sections
- Fully responsive layout
- Lazy loading for performance
